# 🗺️ Avalon Maps

Manage and explore the Roads of Avalon with ease.

## 📜 Map Information

Use the `/ava check` command to see details about a specific map, including:
*   Resources available.
*   Chest locations.
*   Static dungeons.
*   Map image.

**Usage:** `/ava check map_name:MapName`

## 🛤️ Shortest Route

Find the fastest way between multiple Avalon maps. You can specify up to 10 maps to find the shortest path.

**Usage:** `/ava route hours:2 route1:MapA route2:MapB`

## 👹 Boss Guides

The bot includes detailed guides for Avalonian Bosses. These guides cover mechanics, phases, and recommended builds.

**Usage:** `/ava boss`
*   Select the boss you want to learn about from the interaction menu.

---

> [!IMPORTANT]
> Map resource levels can be updated by administrators using `/ava edit`. Help keep the map data accurate for your guild!
